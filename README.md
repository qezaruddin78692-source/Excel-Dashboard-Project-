# Excel Sales Performance Dashboard

## Project Overview

This project focuses on analyzing sales performance using Microsoft Excel.

An interactive dashboard was developed to monitor sales executive performance, compare total sales, evaluate target achievement, and identify performance gaps across different cities.

The dashboard helps users understand sales performance through interactive filters, summary tables, and visual charts.

## Dashboard Preview

![Sales Performance Dashboard](screenshots/dashboard-preview.png)

## Key Features

- City-wise sales filtering using interactive slicers.
- Sales performance comparison between executives.
- Total sales analysis.
- Target achievement percentage analysis.
- Identification of sales performance gaps.
- Interactive charts for better data visualization.

## Dashboard Components

### 1. Sales Performance
Displays total sales generated by individual sales executives.

### 2. Target Achievement
Analyzes the percentage of targets achieved by sales executives.

### 3. Performance Gap
Highlights how far sales executives are from their assigned targets.

### 4. Interactive Dashboard
Includes city filters for:
- Chennai
- Mumbai
- Delhi
- Nagpur
- Patna
- Pune
- Ranchi
- Surat

## How to Use

1. Download the Excel workbook.
2. Open it using Microsoft Excel.
3. Use the city slicers to filter the dashboard.
4. Explore sales performance and target achievement.
5. Refresh the data when the underlying dataset changes.

## Project Objective

The objective of this project is to transform raw sales data into meaningful insights through interactive dashboards and visual reporting.
